# Mutual Fund Analysis

## Overview
This project analyzes mutual fund datasets and performs data ingestion, validation, and live NAV extraction using the MFAPI.

## Features
- Load and inspect 10 CSV datasets
- Fetch live NAV data from MFAPI
- Fetch NAV history for multiple mutual fund schemes
- Explore fund master data
- Validate AMFI scheme codes
- Generate data quality summary

## Tech Stack
- Python
- Pandas
- NumPy
- Requests
- SQLAlchemy
- Matplotlib
- Plotly
- Jupyter
